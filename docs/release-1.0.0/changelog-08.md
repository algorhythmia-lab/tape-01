# SYS 01 / 1.0.0 candidate changelog

2026-10-15. **Development candidate; release decision NO-GO.** The full desktop
release remains available at no charge when qualified. No public release or tag
has been created. This is the final user-facing changelog prepared for review;
the root CHANGELOG.md remains the historical build-input snapshot.

- Stereo effect/generator: bytebeat and cellular generate with silent input;
  transform records and processes external stereo audio.
- FLUX/BIAS, RUN, shared binary STATE, direct domain selection, BRAKE, smoothed
  output and dry bypass; four existing factory studies retain their names/order.
- Vector spool editor, eight-element DSP register, mapped numeric entry,
  keyboard controls, parameter undo/redo and uniform 100/125/150/200% scaling.
  Native assistive technology and complete in-host usability remain unqualified.
- Bounded schema-1 host state with coherent deterministic parameter recall and
  empty tape. Reopen, RESET, presets and sample-rate preparation clear audio
  history; undo cannot recover it. Record/bounce performances to preserve sound.
- Positioned VST3 automation preserves every accepted point and offset; MIDI
  CC20–23 supplies transient FLUX/BIAS/run/domain performance input. AU ordinary
  and scheduled automation still fails the accepted offset contract.
- Pinned dependencies, corresponding source snapshot, selected AGPL-3.0-only
  text/notices and exact-byte validation reports accompany local packets.

Planned formats remain macOS VST3/AU and Windows VST3. The available packet is
macOS arm64 only, ad-hoc sealed, without Developer ID/notarization or a qualified
installation. There are **no qualified supported OS/CPU/DAW configurations**.
One scoped Live 12.4.6 observation does not establish general support.

Three P1 issues remain open: AU offsets, observed callback timing breaches and
complete native callback locks/ownership. DC/listening, host/accessibility,
five-musician tasks, eight-instance/eight-hour soak, rights/corresponding-source
review and signed clean-system lifecycle gates remain unresolved. No exception
has been accepted for these findings.

Host sync, MIDI learn, captured-audio recall, mix control, separate instrument/FX
IDs, public standalone, Max for Live delivery, CLAP/AAX and hardware remain deferred.
See FIRST-MINUTE.md and INSTALL.md in the packet for operation and recovery.
