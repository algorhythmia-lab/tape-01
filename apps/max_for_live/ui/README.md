# UI assets

Reserve source assets here for TIME, FORM, PLAY, MODE and scene selection. The editable integration patch is `../patchers/study01.maxpat`. Use Live parameter-enabled controls and meaningful accessible names when building the release interface. The current patch exposes plain controls for algorithm validation.

For the comprehensive design system, GUI layout, MIDI CC mappings, and 16-LED halo ring behaviors, consult the master software UI specification:
- [`sys-01/docs/vst-reference-ui-spec.md`](../../../docs/vst-reference-ui-spec.md)
